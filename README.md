# 📅 Dynamic Bangla Multi Calendar

A modern, fast, and feature-rich **Dynamic Bangla Calendar** web application. Breaking the limitations of conventional Bangla calendar apps, it integrates astronomical and geographical calculations to offer unique features.

🌐 **Live Web App:** [Click here to view the Calendar](https://xilodegaze.github.io/bangla-calendar/)

---

## ✨ Key Features

* **🗓️ Accurate Bangla Date & Day:** Displays today's Bangla date, month, year, and weekday based on precise mathematical rules.
* **🌅 Live Sunrise & Sunset:** Real-time sunrise and sunset schedule based on the user's location.
* **☀️ Day Length:** Calculates total daylight duration (hours and minutes) based on sunrise and sunset times.
* **🌾 Six Seasons Representation:** Automatically displays the current traditional season (Summer, Rainy, Autumn, Late Autumn, Winter, Spring) matching the Bangla month.
* **🌕 Moon Phase Tracking:** Astronomical calculation to observe lunar phases including New Moon, Full Moon, Waxing, and Waning moons.
* **📱 Smooth Swipe Feature:** Intuitive mobile touch interface to swipe left or right for easy month navigation.
* **⚡ Lightweight & Fast:** Built with pure JavaScript without heavy frameworks, loading instantly on any device.

---

## 💡 Why is this Calendar Unique?

Most Bangla calendars available on web or app stores only show basic dates and holiday lists. This app uniquely combines **Six Traditional Seasons, Day Length, and Astronomical Moon Phases**—delivering a completely fresh and unique experience for a Bangla calendar.

---

## 🛠️ Tech Stack

* **HTML5:** Structure and content layout.
* **CSS3:** Modern, attractive, and responsive UI design.
* **JavaScript (ES6+):** Algorithms for date conversion, sunrise/sunset, and lunar phase calculations.
* **GitHub Pages:** Live web hosting.
